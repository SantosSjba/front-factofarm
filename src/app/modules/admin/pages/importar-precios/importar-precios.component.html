Importar precios
  1. Sirve para cambiar de una vez los precios de muchos productos que ya existen, por ejemplo cuando llega una nueva lista del proveedor.
  2. Cada fila se busca por el código interno del producto: los que no lo tengan o no existan aparecen como error y no se tocan.
  3. Es lo mismo que Productos → Importar → «Actualizar precios».

  1. 1. Descarga la plantilla

    Pulsa «Importar precios» arriba: la plantilla está en esa ventana. Llénala sin cambiar sus columnas.

  2. 2. Revisa la vista previa

    Al elegir el archivo verás cuántos productos cambiarían y qué filas tienen errores.

  3. 3. Confirma

    Solo se actualizan las filas válidas. Las demás se listan para que las corrijas.
